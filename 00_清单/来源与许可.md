## 结论

- 能合法、免登录、直接进 Three.js 的只有 **3dassets.dev 的 CC0 套件**，所以 16 座球队球场是用它 + 每队独立形制参数拼出来的。
- 队名/口号/队徽字的牌匾贴图是**本地生成**的（Windows GDI+，`_work/gen-banners.ps1`），没有引入任何第三方图像：
  文字用队名与公开口号（永远争第一 / 蓝魔 / 雄起 / 白玉碗 / 中原铁军 / 足球城 / 鹏城 / 海牛 / 三镇 / 铁人 / 铜梁龙 / 黄龙 / 高原 / 西海岸 等），
  图形是城市简称画的圆形徽记，**不含真实队徽/赞助商标识**（真实队徽有商标问题，项目既有约定也是不使用）。
- 如果你想让某几座换成上面没下的模型：把账号里的原始文件（.blend/.fbx/.glb）拿到 `01_源模型/` 下，
  在 `tools/build.mjs` 的 `bakeGLB()` 里加一行摆放即可（保存为 GLB 最省事，FBX/OBJ 需要先转 GLB）。
- 用 CC-BY 的 Sketchfab 模型时记得在发布物里署名作者 + 许可链接；CGTrader 免费模型要先看单模型条款。
