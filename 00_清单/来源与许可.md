# 来源与许可

本包的元素分两类：**图是程序画的**，**字是公开报道里的**。这份文档把「每队用了什么、依据在哪、链接是什么」逐条列清楚。

## 一、图形从哪来

208 张 PNG 全部由 `tools/gen-assets.ps1` 用 Windows GDI+ **现场绘制**：帧内几何（旗形、条纹、圆环、图标、色卡格）、渐变色块、文字排版。

- **不含**真实队徽、俱乐部官方视觉、赞助商标识、球员肖像、吉祥物美术形象。
- 徽记（`03_徽记与吉祥物/`）用的是**城市简称字**（港/申/京/蓉/泰/浙/津/滇/岸/豫/连/鹏/牛/汉/辽/渝），与 `球场包` 的既有约定一致。
- 吉祥物只以**文字 + 图标**记录（如「伊戈（海鹰）」「巴布（象）」），没有画形象。
- 配色取自项目内 `dist/game/data/football-index.js` 的 `clubs[].p / s`，属事实性数据。

## 二、文字从哪来

口号、助威词、TIFO 字样、吉祥物名字、球迷组织名来自公开报道（媒体、俱乐部官网、足协公告等），属球迷文化引用。
每队下面列出「元素 → 依据 → 链接」。若要公开发行，建议把含特定历史事件的 TIFO 标题换成自写版本：
改 `tools/art-direction.json` 里那一行，重跑 `build.mjs` + `gen-assets.ps1` 即可。
