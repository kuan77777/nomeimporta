# 16 队融合总览（球场包 × 元素包）

把元素包贴进 `球场包` 的 16 座球场，用**同一套参数化摆法**跑出来，验证「元素包能落到真实几何上」。

![16 队内场](07_预览/全队融合/16clubs-inside.png)

## 一、新规则：图像只出现一次，文字可重复

按你的要求改的：

| 类型 | 每座球场上限 | 说明 |
|---|---|---|
| 大旗 / 双杆旗 / 布幔 / 座席拼图 / 围巾 / 徽记 | **各 1 次** | 图像类不重复，避免满场同款 |
| 地方符号 1/2/3、饮食 1/2 | **各 1 次** | 同上 |
| 主场标语条幅 / 助威词条幅 | **各 5 次** | 文字类可以多挂，像真实球场那样反复出现同一句口号 |

配额表在 `tools/viewer-csl.html` 的 `QUOTA` 里，改数字即可调整；超出配额会自动跳过，不会报错。

## 二、摆法：不填坐标，靠射线找墙

每座球场的形制不同（1 层/2 层/3 层、有无罩棚、看台进深），写死坐标一定会穿帮。所以：

1. 载入该队 GLB → 取包围盒（场地中心为原点，+z 是南门）。
2. 对球场网格做射线探测（`Raycaster`）：
   - 场内：从场地中心朝 **−z** 打，命中就是北看台立面 → 挂布幔；
   - 朝 **±x** 打 → 东西看台前沿 → 挂助威条幅；
   - 朝 higher-y 打 → 看台上层 → 放座席拼图（和布幔拉开 6 m 以上才放）；
   - 场外：从南侧 300 m 外朝 −z 打 → 命中主立面 → 挂徽记/标语/符号/饮食牌。
3. 室内：读该队 `colliders.json` 的 `walkway` / `room` / `opening` 盒，得到环廊中线、房间门面、通道位置，再对墙打射线挂条幅。
4. 牌面朝向 = 从命中点指回射线起点（`lookAt`），所以不会出现「贴在墙上却是反的」。

关键代码：`probe()` / `hangOnWall()` / `placeAll()`，都在 `tools/viewer-csl.html`。

## 三、5 个机位（每队）

| 机位 | 内容 |
|---|---|
| `inside` | 场内正视北看台：布幔 + 大旗 + 拼图 + 围巾 |
| `stands` | 看台视角：拼图在上、布幔在中、旗在两侧 |
| `outside` | 外景 3/4：门面徽记、标语、符号牌、外场饮食摊 |
| `concourse` | 环廊：看台侧标语 + 房间侧助威条幅（机位由碰撞盒推） |
| `hall` | 门厅：出口上方横标 |

另有 `corner` / `tunnel` / `aerial` 可用：`node tools/shot-csl.mjs <输出目录> corner tunnel aerial`。

## 四、图纸与运行

```powershell
cd 球场特色元素包/tools

node build-viewer-data.mjs                 # 汇总 16 队：GLB 路径 + 13 张资产 URL + 配色/口号
node shot-csl.mjs "..\07_预览\全队融合"     # 16 队 × 4 机位（默认 inside/stands/outside/concourse）
node shot-csl.mjs "..\07_预览\全队融合" hall --teams=beijing_guoan,shanghai_shenhua
powershell -File sheet-csl.ps1 -SrcDir "..\07_预览\全队融合" -OutDir "..\07_预览\全队融合"
```

> 无头 Chrome 在受限沙箱里起不来（crashpad 访问进程句柄被拒），**截图这一步需要一次性放开权限**。
> 一次会话里循环切 16 队，比每队单开一次浏览器快很多（整批约 3–5 分钟）。

## 六、批量跑出来的 4 个坑

1. **贴图必须预载**：`TextureLoader.load` 是异步的，摆完立刻截图会拍到「白面板」。
   现在先用 `loadAsync` 全部解码进 `texCache`，再摆放（`imgs` 计数等于贴片数才算过）。
2. **摆放前要 `updateMatrixWorld(true)`**：否则射线全部打空，元素一个都不出现。
3. **资产路径必须是 URL**：Windows 的 `path.join` 会给出反斜杠，浏览器 404 → `alphaTest` 把贴片当透明丢掉，画面看着「什么都没贴」。
4. **室内机位不能写死**：1 层和 3 层球场的环廊位置差很多，写死的 `z=86.5` 会跑到墙里或墙外。
   现在从 `walkway` 盒推出走廊中线与门面位置，16 座都能落在真实走廊里。
