# 元素分类规范

本文件定义「球场特色元素包」的 6 类元素、命名规则、贴图规格与字段语义。
要加一支球队、增一类元素、或把包接进引擎，看这一份就够。

---

## 1. 元素分类总表

| key | 目录 | 元素类型（`assets[].type`） | 每队 | 尺寸 | 透明 | 用途 |
|---|---|---|---|---|---|---|
| `flag` | `01_旗帜与TIFO` | `flag-main` | 1 | 1024×1536 | 否 | 竖幅挂旗（带套筒、鸡眼扣），挂看台栏杆/灯柱 |
| | | `flag-terrace` | 1 | 1536×1024 | 否 | 球迷双杆横旗，看台挥舞 |
| | | `tifo` | 1 | 2048×1024 | 否 | 整面看台拉的巨幅布幔（带打孔边） |
| | | `mosaic` | 1 | 1024×1024 | 否 | 观众举色卡组成的图案（座位拼图） |
| `text` | `02_标语与助威` | `banner`（×2） | 2 | 2048×256 | 否 | 长条幅：主场标语 / 助威词 |
| | | `scarf` | 1 | 2048×384 | 否 | 助威围巾（针织色块 + 流苏） |
| `crest` | `03_徽记与吉祥物` | `badge` | 1 | 768×768 | 是 | 圆形城市简称徽记 |
| `symbol` | `04_地方文化符号` | `symbol`（×3） | 3 | 512×512 | 否 | 城市符号牌（图标 + 中文名） |
| `food` | `05_球场饮食` | `food`（×2） | 2 | 768×384 | 是 | 饮食招牌（圆角、透明外框） |
| `config` | `06_看台氛围配置` | — | 1 | JSON | — | 引擎侧参数 |

合计 **13 张 PNG + 1 份 JSON / 队**，16 队共 208 张。

## 2. 命名规则

```
<teamId>_<asset>[_<n>].png
```

- `teamId`：小写下划线，与 `tools/teams-base.json` 的 `id` 一致（如 `beijing_guoan`、`shanghai_port`）。
- `asset`：`flag_main` / `flag_terrace` / `tifo` / `mosaic` / `banner_slogan` / `banner_chant` / `scarf` / `badge` / `symbol_1..3` / `food_1..2`。
- 例：`01_旗帜与TIFO/chengdu_rongcheng_tifo.png`

**不要改名**：`06_看台氛围配置/*.json` 与 `elements.json` 用路径引用资产，改名会让 `verify.mjs` 报错。
要加新资产，走 `tools/art-direction.json` → `build.mjs` → `gen-assets.ps1` 的正规流程。

## 3. 每类元素长什么样（可画的边界）

### 3.1 旗帜与 TIFO

| 元素 | 构成 | 摆放建议 |
|---|---|---|
| 主场大旗 | 顶部套筒 + 左侧两道队色竖条 + 圆形徽记（城市简称字）+ 队名 + 底部口号缎带 + 左侧 3 个鸡眼扣 | 垂直挂：看台栏板、灯柱、通道口上方；`PlaneGeometry` 直接贴 |
| 看台双杆旗 | 对角双色分割 + 超大助威词（带描边）+ 底部队名条 + 四角鸡眼扣 | 球迷手里 / 栏杆斜挂；建议 2:1 以内缩放 |
| 巨幅布幔 | 队色渐变底 + 右侧淡色大图标水印 + 主标题 + 1-2 行副标 + 上下打孔边 | 覆盖整段看台；建议做成轻微曲面（`CylinderGeometry` 的一小段） |
| 座席拼图 | 按 `mosaicCols` 分格，三色（亮/中/暗）填充出字形 | **铺到看台座席 UV**；每格 = 一个座位 |

> 文字描边：`TextFit` 的第 12 个参数传颜色即可开启（实现见 `gen-assets.ps1`）。
> CJK 字形用 `GraphicsPath.FillMode = Winding`，否则笔画交叠处会漏底。

### 3.2 标语与助威

- `banner_slogan`：队色底 + 上下细线 + 主文案 + 小注（城市 · 主场）。
- `banner_chant`：底色换成辅色（`flip`），文案是**看台真实喊过的话**。
- `scarf`：五段色块 + 中间深色带压字 + 两端竖条流苏；宽高比 16:3，**别拉伸**。

### 3.3 徽记与吉祥物

- `badge`：外环（辅色）→ 内圆（主色压暗）→ 城市简称字 → 3 个点（可用 `stars` 改 1-5）→ 底部城市名。透明底。
- 吉祥物**不作画**，只记录在 `elements.json` 的 `identity.mascot`（`name` / `desc`）；
  吉祥物类视觉要走 `04_地方文化符号` 的图标牌（如 `henan_symbol_1` = 大象 = 巴布原型）。

### 3.4 地方文化符号

每队 3 个，从调研里挑「一眼能认出是这座城」的：

- `kind` 取值：`landmark` / `food` / `heritage` / `dialect` / `animal`；
- 图标取自 30 种内置（见第 5 节），牌面 = 渐变底 + 细边框 + 图标 + 底部中文名；
- 用途写在 `use` 字段（例：「做花形环场拼图」「场外非遗摊位」），给场景美术看。

### 3.5 球场饮食

- 圆角招牌，左侧圆形餐盘 + 图标，右侧菜名 + 一行小注；
- 小注是**城市味**（「本地读 gala · 配冰啤」「提起来像灯笼」），不是价格；
- 透明底，方便贴灯箱或吊旗。

```jsonc
{
  "meta": {
    "name": "中超 16 队球场特色元素包",
    "version": "1.0.0",
    "generatedAt": "…",
    "teams": 16,
    "assets": 208,
    "categories": [ { "key": "flag", "folder": "01_旗帜与TIFO", "label": "旗帜与 TIFO", "note": "…", "hint": "…" } ],
    "preview": { "categoryTitleFormat": "{folder} · {label}", "teamSheetTitle": "每队元素全套", "teamSheetSub": "…", "missingLabel": "缺失" },
    "licenseNote": "…"
  },
  "teams": [
    {
      "id": "beijing_guoan",
      "cn": "北京国安",
      "en": "BeijingGuoan",                 // 与「球场包」目录名一致的英文名
      "gameId": "C234",                     // dist/game/data/football-index.js 的 clubs[].id
      "city": "北京",
      "venue": "北京工人体育场",             // 本包口径（跟球场包），差异见 venueNote
      "venueNote": "…",                     // 可选：调研核实到的现主场
      "stadiumPackFolder": "03_BeijingGuoan",
      "palette": { "primary": "#00703C", "secondary": "#FFFFFF", "accent": "#F2C200" },
      "emblem": "京",                        // badge/flag/mosaic 用的城市简称字
      "nickname": ["御林军", "国安"],
      "identity": {
        "ultras":         [ { "name": "御林军", "note": "…" } ],
        "chants":         [ { "text": "国安国安，北京国安", "kind": "chant", "note": "…" } ],
        "tifo":           [ { "title": "…", "desc": "…", "when": "…" } ],
        "flags":          [ { "desc": "…", "note": "…" } ],
        "mascot":         { "name": "京狮", "desc": "…" },
        "localSymbols":   [ { "item": "国槐", "kind": "landmark", "use": "…" } ],
        "food":           ["炸酱面", "卤煮火烧"],
        "venueFeatures":  ["…"],
        "slogan": "永远争第一",               // 落到 banner_slogan 的那句
        "chant":  "国安必胜"                  // 落到 banner_chant 的那句

```

`assets[]` 里除 `type/file/w/h/label` 外的字段是**绘制参数**，由 `gen-assets.ps1` 按 `type` 取用：

| type | 绘制参数 |
|---|---|
| `flag-main` | `title` `sub` `glyph` `slogan` |
| `flag-terrace` | `title` `text` `sub` `onSecondary` |
| `tifo` | `title` `lines[]` `icon` |
| `mosaic` | `glyph` `cols` |
| `banner` | `text` `sub` `flip` |
| `scarf` | `text` `sub` |
| `badge` | `glyph` `sub` `stars` |
| `symbol` / `food` | `icon` `title` / `sub` |

## 5. 图标库（30 种）

`mountain` `fire` `dragon` `hotpot` `skewer` `noodle` `dumpling` `beer` `panda` `tiger` `bull` `bird`
`lighthouse` `bridge` `port` `gate` `pagoda` `tvtower` `waves` `bamboo` `lotus` `seagull` `fish` `city`
`shield` `tree` `lion` `elephant` `dog` `robot`

加图标：在 `gen-assets.ps1` 的 `Icon` 函数里加一个 `'kind' { … }` 分支，
坐标一律按 **0..100 的方框**写（用 `$X` / `$Y` / `$f` 三个换算闭包），再在 `art-direction.json` 里引用。

## 6. 看台氛围配置（`06_看台氛围配置/<id>.json`）

```jsonc
{
  "id": "chengdu_rongcheng",
  "gameId": "C233",
  "cn": "成都蓉城",
  "venue": "成都凤凰山体育公园",
  "palette": { "primary": "#E4002B", "secondary": "#F2C200", "accent": "#FFFFFF", "seatTint": "#F2C200" },
  "tifoCoverage": 0.42,            // 0-1：布幔/拼图覆盖看台的比例
  "mosaic": { "asset": "01_旗帜与TIFO/chengdu_rongcheng_mosaic.png", "cols": 48 },
  "chant": {                        // 助威循环
    "bpm": 112,                     // 鼓点速度，越高越急
    "loop": true,
    "lines": [ { "text": "雄起", "kind": "chant", "gapSec": 6 } ]
  },
  "flags":   [ { "asset": "…flag_main.png", "anchor": "north-rail", "count": 4 } ],
  "banners": [ { "asset": "…banner_slogan.png", "anchor": "facade", "count": 1 } ],
  "scarf": "02_标语与助威/chengdu_rongcheng_scarf.png",
  "crowd":  { "primaryRatio": 0.74, "secondaryRatio": 0.18, "accentRatio": 0.08 },  // 人群三色配比，和为 1
  "props":  [ { "asset": "04_地方文化符号/…symbol_1.png", "zone": "concourse", "note": "…" } ],
  "smoke":  { "enabled": true, "color": "#E4002B" },   // 烟火/烟雾特效
  "note": "…"                                          // 这队氛围的依据
}
```

`anchor` / `zone` 是抽象挂点名，建议在场景里这样落位：

| 挂点名 | 场景位置 |
|---|---|
| `north-rail` | 北看台栏板 |
| `ultras-block` | 死忠看台（球门后） |
| `facade` | 主立面 / 门洞上方 |
| `tier-front` | 看台前沿（上下层交界） |
| `concourse` | 环廊（展板 / 打卡点） |
| `market` | 外场集市 / 小卖部 |

`index.json` 是 teamId 列表，`clubId-map.json` 是 `clubId → teamId` 映射（16 条，勿手改成不一致）。

## 7. 加一支球队（5 步）

1. `tools/teams-base.json` 加一条：`id / cn / en / folder / city / venue / primary / secondary / accent / emblem / gameId`。
2. `tools/research/<id>.json` 写调研：`ultras / chants / tifo / flags / mascot / local_symbols / food / venue_features / sources`（**必须有来源 URL**）。
3. `tools/art-direction.json` 加一条：旗上字、TIFO 标题与两行副标、标语、助威词、围巾、徽记副标、3 个符号（含 `icon`）、2 个饮食（含 `icon`）、`atmosphere`。
4. `node build.mjs` → 会打印队数/资产数与校验结果；有缺项会 `exit 1`。
5. `gen-assets.ps1` → 出图；`preview.ps1` → 更新预览；`verify.mjs` → 验收。

> 17 队以后记得同步改 `verify.mjs` 里的 `EXPECT`（teams / total / `wantPerType`），否则会按 16 队报错。
