# 融合演示 · 北京国安（北京工人体育场）

用 `球场包` 的国安球场 GLB + 本包的 13 张元素贴图，做了 8 个机位的第一版「贴上去到底什么样」，
用来验证 **`06_看台氛围配置` 的挂点语义**能不能落地，以及贴图尺寸、透明、可读性有没有坑。

![内场正视](../07_预览/国安融合/guoan_stands.png)

## 一、怎么做的

- 渲染：`tools/viewer-guoan.html`（three.js 单页，`_work/three-local` 的 three + GLTFLoader）
- 载入：`球场包/02_球队球场/03_BeijingGuoan/BeijingGuoan_stadium.glb`（193 × 230 m，73,784 三角面）
- 贴片：全部用 `MeshBasicMaterial`（无光照、双面、带 alphaTest），保证元素在夜景里也读得清
- 截图：`tools/shot-guoan.mjs`（本地静态服务器 + 无头 Chrome + CDP 逐机位截图 → `07_预览/国安融合/`）

```powershell
# 需要一次性放开权限：无头 Chrome 在受限沙箱里会被 crashpad 的进程句柄访问拦住
node tools/shot-guoan.mjs "D:\异想天开\球场特色元素包\07_预览\国安融合"
node tools/shot-guoan.mjs "…\07_预览\国安融合" inside stands        # 只出指定机位
```

## 三之二、内部装饰（按碰撞盒的真实坐标贴）

内部几何全部取自 `球场包/…/BeijingGuoan/colliders.json`，不是估的：

| 部位 | 可贴的墙面 | 坐标 | 贴了什么 |
|---|---|---|---|
| 门厅 | 迎面墙（z=94.4）、两侧墙（x=±12.6） | 0, 2.75, 93.74 / ±12.52, 91.6 | 徽记 + 两侧垂旗 + 围巾；出口上方 9×1.12 横标 |
| 环廊·看台侧 | 看台外表面 z=±84.5、x=±65.9 | y 3.1–4.7 | 主标语/助威词 + 8 面垂旗（**走在环廊里抬头就能看到**） |
| 环廊·房间侧 | 房间门面 z=±89.3、x=±70.8 | y 2.55 | 每个门口一枚徽记；商店双联符号；小卖部/后厨饮食牌；更衣室条幅 |
| 环廊·外墙 | z=±93.8 | y 5.2–5.4 | 大标语与徽记（**只在房间之间的空档、门厅背后露出**） |
| 球员通道 | 两壁 z=±2.54，x 33.4…66.3 | y 2.05（徽记）/ 4.0（条幅） | 5×2 枚徽记阵列 + 两侧口号；通道口对场内一面 10×5 布幔 |
| 室内照度 | — | — | 模型没有室内灯，另补 16 盏环廊点光 + 12 盏房间门口光带 + 2 盏通道光 |

内部布局要点（照抄到别的球场前必须知道）：

- **房间占据了环廊外侧 4.4 m**（南侧 z 89.3–93.7），真正能走的环廊只有 **5 m 宽**（z 84.4–89.3）。
  所以镜头要放在 z≈86.6，放 89.8 会直接钻进房间里（第一版就这么糊了）。
- **外墙（z=93.8）被房间挡住**，把主视觉放上去等于白贴；要贴就贴**看台外表面（z=84.5）**。
- 房间门面是一整条连续墙，**门洞位置不在碰撞盒里**，所以门口牌子统一放房间中心线，
  避开 y<2.4 的门洞高度。


## 四、这轮试出来的 5 个坑（接其它 15 队前先看）

1. **别强行给 GLB 打开 `vertexColors`**：国安球场里自带的「北京国安」招牌是独立贴图面片，
   强制 `vertexColors = true` 会让它变成一块黑板。正确做法是只有几何真带 `COLOR_0` 时才开：

   ```js
   m.vertexColors = !!o.geometry.getAttribute('color');
   m.needsUpdate = true;
   ```

2. **座席拼图必须放在「整片看台」上**，且**要在看台靠上、面积够大**才有辨识度。
   一开始放在东看台（32×16）时，从场内看只有指甲盖大小；挪到北看台上层 34×17 后，`京` 字一眼可读。
   实际接引擎时按 `mosaicCols` 对齐座位数，别按米数硬贴。
3. **饮食牌要「落地」**：招牌中心高度 ≈ 高度 / 2 时才像摊位灯箱；吊在 2.6 m 会读成「浮空面板」。
4. **大旗别压在布幔上**：4 面竖旗放在布幔两侧（x ±33/±46）比放在中间更清楚；同一挂点多面旗要错开 x。
5. **浅色辅色的队（国安白、蓉城黄）双层旗要描边字**：本包的 `flag-terrace` 已经内建描边，
   但接引擎时如果用 `MeshBasicMaterial` + 双面，注意 `alphaTest` 别设太高（会吃掉描边）。
6. **双面板从背面看是镜像字**：门厅「出口上方横标」第一版朝里贴，从门厅看过去全是反字。
   室内贴片要先想清楚「人站在哪一侧」，不是「贴到哪个面」。
7. **室内必须自己补光**：这套 GLB 只有室外方向的照度，环廊/通道/门厅默认是黑的（第一版室内图几乎全黑或糊白）。

## 五、还没做的（有意留给引擎）

- 旗面没有布料摆动；拼图没有逐座位明暗；没有观众（球场自带 1100 个低模观众未逐一检查）；
- 所有贴片是「平面板」，没做厚度与投影；夜景的灯光是临时补的两盏点光，不是真实照度。
- 这些都属于引擎里的一行参数或一个 shader，不属于元素包范围。
